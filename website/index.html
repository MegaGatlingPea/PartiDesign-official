From new molecular identities to fixed-identity docking, use one framework with the context and constraints your design needs.

01 / PROTEIN

Proteins, peptides & antibodies

Generate monomers and binders, scaffold residue or atomic motifs, and guide secondary structure. Design linear, cyclic and crosslinked peptides, or selected CDRs in paired VH/VL and VHH scaffolds. Fixed-identity peptides support docking.

02 / NUCLEIC ACIDS

DNA & RNA

Design aptamers around proteins or small molecules, or generate structures for fixed sequences. Combine paired/unpaired, specified-pair and stem-loop guidance with sequence and motif conditions. Fixed-identity ssRNA supports docking.

Ligands & molecular fragments

The iterative pipeline

One command for de novo design and structure-guided redesign.

Connect generation, partial diffusion, MPNN sequence redesign, refolding and final validation in one runner. Start from a task YAML or an existing complex.

Start from your task

Use a design YAML, or describe starting complexes and design chains in annotation.csv.

Keep native constraints

Fixed identities, motifs and chemical connections remain part of the task through refinement.

Collect accepted candidates

Refold and filter between rounds, then apply the selected preset’s final validation.

Your first insulin receptor binder

partidesign pipeline configs/examples/pipeline_tasks.yaml \
  --task protdbench_insulin_receptor --preset ppi \
  --config configs/pipeline/demo.yaml --run-name insulin_receptor_demo

The lighter demo runs three rounds with ESMFold2-fast, relaxed pipeline screening and partial diffusion, followed by five Mol-1 samples for final validation. Prepare the environment and demo models below.

Refine an existing peptide complex

partidesign pipeline configs/examples/optimization \
  --config configs/pipeline/optimize.yaml --preset ppi \
  --run-name peptide_optimization

Optimize the bundled linear and cyclic peptide complexes. The directory’s annotation.csv describes each starting complex. This workflow begins with partial diffusion and uses the full selected preset for final validation; prepare its evaluation models.

Optimize a GLP1R VHH

partidesign pipeline configs/examples/antibody_opt \
  --preset antibody --run-name glp1r_vhh_optimization

Use the antibody preset with the bundled annotated starting complexes. Native CDR/framework permissions and the paratope declaration guide optimization. See the antibody pipeline guide for model requirements and final validation.

Set up the environment

Use Linux with an NVIDIA GPU and Conda or a compatible environment manager. Follow the commands below from your working directory.

01 Clone and install

git clone https://github.com/MegaGatlingPea/PartiDesign-official.git
cd PartiDesign-official
conda env create -f partidesign_cu12.yaml
conda activate partidesign

For CUDA 13 and alternative setups, see the environment guide.

02 Download the models

Download the PartiDesign generation bundle and save it as ckpts/partidesign.ckpt. This checkpoint is a separate download from the environment installation.

Then prepare the additional models for the lighter insulin receptor pipeline demo:

Additional demo models

partidesign download esmfold2-fast mol1 solublempnn

The download guide covers terminal downloads, model locations and predictors required by full presets.
